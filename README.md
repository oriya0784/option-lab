# 星辰期權練習室 · Option Lab v0.6.0

**線上遊玩：[星辰期權練習室](https://oriya0784.github.io/option-lab/)**

虛構歐式指數期權交易遊戲，無需帳號、API key、套件安裝或真正資金。以 `python -m http.server 8765 --bind 127.0.0.1 --directory dist` 啟動，再開啟 http://127.0.0.1:8765/。

## 已實作

- 買／賣 Call、買／賣 Put，開倉與平倉分開；部分平倉、限價平倉、停損市價平倉。
- 自由履約價（最多兩位小數）；按一次加減 1，長按連續，5 秒後每次加減 10。到期可選 1～365 交易日，各筆獨立結算。
- 每日 6 輪模擬撮合；Bid／Ask 與有限深度、部分成交、市價 IOC、限價 DAY／GTC、撤單、合約到期取消掛單。
- 每口每腿每次成交費 15、現金與權益、保證金與委託保留、強制平倉、負債與破產。
- 牛市 Call／Put 價差、熊市 Call／Put 價差、買入跨式、買入 Call 蝴蝶價差、鐵兀鷹；整組撮合與平倉，同種類同到期價差保證金配對。
- 模擬消息跳空、IV 偏斜與期限結構、四種市場情境；帳戶／指數圖、Greeks、到期損益圖、情境試算。
- 12 堂聚焦教學，共 186 步、17 題問答：認識畫面 23 步、基礎實作 25 步、七種策略各 13～15 步、情境風險 15 步、部位停損到期 18 步、設定存檔 7 步。介紹點任意處繼續，操作只接受指定控制。每堂使用獨立帳戶，結束／退出還原原本帳戶、委託與畫面設定。
- 每種策略都有選擇、履約價距離、腿部配置、成本／兩平／到期最大損益、理解題、整組開倉和平倉。下單區可直接開啟當前策略課；記錄各堂完成進度，能隨時重練。
- 下單區依選擇顯示策略用途、保護條件、時間與 IV 影響；淨權利金明示收或付。極窄收款策略被 Bid／Ask 吃成淨支出時顯示提示。跨式隱藏無作用的距離欄；履約價標籤說明主腿或中心。
- 情境試算新增三個單變數快捷鍵（指數 +10%、IV +5 個百分點、經過 7 日）與歸零，便於比較；不改動市場或帳戶。
- 認識畫面的問句、選項與解釋改用完整白話句子，說明哪些交易會受益於上漲，以及買 Call 與賣 Put 的風險差異。
- 瀏覽器自動存檔、JSON 匯出與驗證後匯入、練習足跡、動畫開關與減少動態效果偏好。
- 星辰夜空主題：金黃五角星、粉紅四角星、淡紫彗星與淺藍六角星，分布於帳戶、報價、下單、持倉與教學區；眨眼、漂浮、星光與點擊星屑動畫。離開可見範圍或切到背景分頁會暫停；教學時暫停環境動畫，關閉特效／系統減少動態效果均可停止。
- WebMCP feature detection：讀取帳戶、開倉、平倉、推進虛擬交易日。

## 模型與現實差異

NOVA 是虛構指數，起始 1,000，每點每口 50。使用簡化 Black–Scholes、252 交易日年與 2% 利率。自訂履約價／到期日是沙盒自由度，非實際掛牌選擇。每日 6 輪不是實際交易所時間表。

歐式、現金結算、無股息。未實作股票／ETF、美式提前行權、提前指派、股票交付、稅務、休市日或真實交割延遲。市價 IOC 只成交最佳一檔，未掃多檔。深度及 IV 都是模型，非實際訂單簿。停損不是成交保證。

保證金使用教學風控與保守垂直價差配對，並非券商完整公式；跨種類及跨到期不抵減。資金不足即時撤單／強平，沒有補繳寬限期。保證金不是損失上限。到期曲線計入開倉費，情境試算不包含途中風控與後續費用。

帳戶資料只保存於本機瀏覽器，不傳至服務器。清除瀏覽器資料將失去存檔；可先匯出 JSON。`?qa` 使用獨立測試存檔，不會覆寫正常帳戶。

## GitHub 版本

儲存庫：https://github.com/oriya0784/option-lab

GitHub Pages 遊戲網址：https://oriya0784.github.io/option-lab/

此份程式對應 v0.6.0。直接使用 `dist/` 內的 HTML、CSS 和 JavaScript，不需要安裝前端套件，也沒有建置步驟。

### 在本機啟動

在儲存庫根目錄執行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

再開啟 http://127.0.0.1:8765/ 。若電腦使用 `python3` 指令，可把上面的 `python` 改成 `python3`。

### 執行測試

使用 Node.js 18 或以上版本，不需要安裝套件：

```sh
node tests/engine.test.cjs
node tests/hold-repeat.test.cjs
```

也可以執行 `npm test`。測試涵蓋期權定價、費用、報價深度、委託／停損、到期結算、策略、保證金／強平、還原，以及長按五秒後的加速。

### 檔案

- `dist/index.html`、`dist/style.css`：介面與星辰動畫。
- `dist/engine.js`：市場、期權、委託、資金與風控模型。
- `dist/app.js`：交易介面、存檔與模擬帳戶。
- `dist/strategies.js`：七種策略的說明與問答資料。
- `dist/tutorial.js`：聚焦教學與操作引導。
- `dist/hold-repeat.js`：長按連續加減與加速。
- `tests/`：不需要瀏覽器的模型與互動邏輯測試。

儲存庫不包含原託管平台的專案設定、憑證、瀏覽器存檔或工作紀錄。GitHub 上的程式不會自動取得既有網站中的本機進度。

## GitHub Pages 發佈

網站由此儲存庫的 `main` 分支、`/(root)` 發佈。根目錄的 `index.html` 直接載入遊戲，`.nojekyll` 讓 GitHub 原樣提供靜態檔案。

修改 `dist/index.html` 後，執行 `npm run build:pages`（或 `node scripts/build-pages.cjs`），將更新後的根目錄入口一併提交。CSS 和 JavaScript 保持在 `dist/`，沒有複製第二套程式。更新 `main` 後，GitHub Pages 會重新部署。

手機、平板與電腦皆可直接開啟遊戲網址，不需在自己的電腦啟動伺服器。進度保存於各裝置的瀏覽器；不同裝置不會自動同步，需匯出與匯入存檔。
